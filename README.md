## Requirements

* Cloudflare account and D1 database.

## Configure

Create a .env file in the repository root:

```
CLOUDFLARE_API_TOKEN=
D1_DB_ID=
ACCOUNT_ID=
OPENAI_API_KEY=
OPENAI_MODEL=
```
